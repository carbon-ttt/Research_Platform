# BioPrint Research Copilot — MVP

面向生物 3D 打印研究者的研究工作台。用户可以登录、建立项目、记录证据与实验设计，并导出一份可审核的 HTML 研究提案。

这是面试用的高保真 MVP：前端零依赖、无需构建、数据存在浏览器本地。

## 快速开始

```bash
cd app
python3 -m http.server 4173
```

打开 <http://localhost:4173>。

演示账号：

```text
邮箱：demo@bioprint.local
密码：demo1234
```

直接双击 `app/index.html` 也能运行，但用本地服务器打开更稳。

## 已实现

**登录**

- 本地注册与登录，密码用 SHA-256 加盐哈希后再存储
- 演示账号一键填充
- 数据按账号隔离，退出后可切换账号

**记录**

- 研究项目的新建与切换
- 研究问题：Copilot 澄清、编辑、确认，并保留来源与修改时间
- 项目上下文：身份、设备、材料、周期、预算
- 知识库：来源条目（类型、年份、DOI 或链接、备注）
- 证据台账：Claim、来源、页码或图表位置、实验条件、指标、强度、类型、支持或冲突关系
- 证据状态流转：待审核到纳入提案，可退回或删除
- 研究备注：导师意见、决策、开放问题
- 实验设计：对照组与实验组、自变量、评价指标、设计风险
- 研究空白：分类、置信度、接受或驳回
- 活动日志：每次修改都写入项目记忆

**导出 HTML**

- 一键导出独立 HTML 提案，内联样式，可直接打开或打印成 PDF
- 包含研究背景、空白、假设、实验设计、时间线、完整证据台账、待审核清单和参考文献
- 明确标注草稿状态、待确认项和未解决的冲突
- 可另导出完整项目记录的 JSON，便于备份

## 项目结构

```text
app/

├── js/
│   ├── store.js   数据层：账号、项目、记录的读写与校验

│   └── app.js     交互层：事件绑定与状态流转
```

## 测试

```bash
node tools/smoke-test.js
```

该脚本在 Node 的 vm 上下文里加载前端脚本，覆盖登录、记录、审核、过滤、页面渲染、HTML 导出和账号隔离。

## 数据说明

当前版本不连接后端、论文数据库或模型服务。账号与项目记录保存在浏览器 `localStorage`（键名 `bioprint.workspace.v2`）。

演示用的文献、实验条件和冲突案例是为界面评审准备的教学素材，不是真实检索结果。接入生产环境前必须替换为真实数据源，并接入文档解析、引用核验和权限体系。

## 已知边界

- 本地认证仅用于演示，不具备生产级会话管理、找回密码或多设备同步
- 搜索为本地文本匹配，不是语义检索或 RAG
- PDF 上传解析、Ontology 与多 Agent 编排不在本版本范围内
- 导出为静态 HTML，尚未支持 DOCX 与 PDF 直出
